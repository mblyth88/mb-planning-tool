# MB Planning Report Tool

Hosted copy of the MB Planning Report Tool for Murray Bell Planning Co.
Open it here: **https://mblyth88.github.io/mb-planning-tool/**

- One self-contained page, runs entirely in your browser; nothing you type or drop in is uploaded anywhere.
- Looks up a Queensland address or lot/plan, reads the council's zoning and overlay mapping (Brisbane, Ipswich, Logan, Redland, Moreton Bay), reads the proposal plan or architectural plans, and builds the planning report (Word + PDF) and a job file for the Code Table Generator.
- Always the current build – bookmark the link above. Version and build date are shown in the header. See CHANGELOG.md.

Maintained by Mitch Blyth (Meliora Engineering). Ipswich mapping comes via the `eplan-relay` feed.
